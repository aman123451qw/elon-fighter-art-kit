# Examples (format reference)

Art from the open game template Elon Fighter is built on. Use it to see what the game expects; our characters, stages and menus are new.

| Folder / file | Shows |
|---|---|
| `brawler_reference.png` | A full-body reference image: stance, framing, flat background |
| `sprite-sheets/` | Game-ready sheets made from clips: 256 x 256 frames, 5 per row, feet on the same line in every frame. This is what our script produces from your clips. |
| `previews/` | The same moves as animated GIFs: timing, on-the-spot movement, how a special charge leads into the special |
| `portraits/` | Portraits with a painted background, facing left |
| `stages/rooftop-sunset-stage.png` | A 2048 x 768 stage: flat floor across the bottom, calm middle |
| `hud/hud-atlas.png` | The health bars and portrait frames the game draws on top of the stage (the top 20% of the screen) |
| `mode-card-example.png` | A menu card |
